Weight-Space Harness Demo

LLM ajanı kendi ağırlıklarını güvenli sandbox'ta düzenlemek için gereken 5 bileşen

1. Tensor Erişim Katmanı

Safetensors checkpoint'ten katman bazında tensor okuma/yazma (read_tensors, write_tensors). Şifreli, imzalı delta üretimi.

2. Forward-Pass Sandbox

Budgetlu (max N pass) inference ortamı. run_forward(input, budget) → logits + activation cache. CPU/GPU seçimi.

3. Eval Harness

Standart benchmark paketi: MATH-500, GSM8K, IFEval, BBH. Otomatik skorlama + regresyon tespiti (pre/post diff).

4. Reviewer Ajanı

Düzenlemeyi yapan ajandan bağımsız ikinci ajan: güvenlik, doğruluk, görev uyumu, yan etki analizi. JSON raporu.

5. İnsan Onay Kapısı

Değişen tensor listesi, öncesi/sonrası skor tablosu,Reviewer raporu → tek tıkla onay/red. Audit log (kim, ne zaman, hangi delta).
